# OriTrainer

奥日与迷失森林双版本修改器，支持原版和终极版，包含

- 无限生命
- 无限能量
- 灵魂链接无需冷却
- 不安全区域建灵魂链接
- 超级跳
- 无限二段跳
- 无限冲刺
- 无限能力点数
- 显示地图
- 死亡数归零
- 100% 探索
- 解锁全部基础技能
- 重置时间
- 获得三把钥匙
- 一命保护（死亡不清档）

等在内的多项功能，项目具体内容请参看 [README](./OriTrainer/README.md)

并随附风灵月影版修改器 [Ori and the Blind Forest Definitive Edition v1.0 Plus 13 Trainer.exe](./Ori%20and%20the%20Blind%20Forest%20Definitive%20Edition%20v1.0%20Plus%2013%20Trainer.exe) （只支持终极版游戏）
